<POST>/channel/test</POST>

用给定渠道配置发送一条测试消息，不落库。`title` / `content` 缺省或为空时使用固定默认文案；渠道配置中的通知尾仍按正常推送逻辑附加。测试发送绕过渠道类型级节流排队（手动单次调用，不占窗口名额），不会因该类型队列繁忙而长时间等待。

两种调用方式二选一：提供 `id` 时按该渠道已保存的配置发送（列表页测试场景，名称与类型也取库内值）；不提供 `id` 时按提交的 `type` / `config` 发送（编辑表单未保存场景，`name` 可省略且不做唯一性校验）。

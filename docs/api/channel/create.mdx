### 通用配置 general

每个渠道的 `config` 都可携带一个可选的 `general` 对象（跨渠道通用配置）。完整说明见[数据关系模型](/docs/api/channel/schema)。

<TypeTable
  type={{
    footer: {
      description: '自定义通知尾，非空时追加到通知正文末尾（与正文空一行分隔），全部渠道生效',
      type: 'string',
    },
    proxy: {
      description: 'HTTP 代理地址，格式 `host:port` 或 `http://host:port`（协议可省略，默认 `http`），仅 HTTP 类渠道生效（`apprise` 走 CLI 不适用）。不填则直连',
      type: 'string',
    },
    messageTemplate: {
      description: '消息模板，占位符 `{{title}}`、`{{content}}`，换行用 `\\n`；仅无独立标题字段的渠道生效（`discord`、`feishu`、`googlechat`、`kook`、`telegram`、`wecombot`、`wecomapp`、`wxpusher`）。不填则默认标题与正文空行分隔，渲染后为空则跳过该渠道推送',
      type: 'string',
    },
  }}
/>

---
title: 代码运行实时日志
---

代码运行（执行命令、运行文件、手动运行任务）期间实时推送日志分片，直到运行结束。

同一 `runId` 的分片按产生顺序推送，`over: true` 表示该次运行结束，之后不再推送。

<Callout icon={false}>
接口路径：`/api/ws`  
事件名称：`run:log`  
方向：服务端 → 客户端
</Callout>

## 载荷

外层为统一响应信封：

<TypeTable
  noRequiredMark={true}
  type={{
    code: {
      description: '状态码（1 表示成功）',
      type: 'number',
      required: true,
    },
    message: {
      description: '提示信息',
      type: 'string',
      required: true,
    },
    type: {
      description: '响应类型',
      type: "'success' | 'error' | 'warning'",
      required: true,
    },
    result: {
      description: '日志数据，字段见下表',
      type: 'object',
      required: true,
    },
  }}
/>

`result` 字段：

<TypeTable
  noRequiredMark={true}
  type={{
    runId: {
      description: '运行唯一标识',
      type: 'string',
      required: true,
    },
    log: {
      description: '日志内容（运行结束时可能不包含）',
      type: 'string',
    },
    stream: {
      description: '输出流（运行结束时可能不包含）',
      type: "'stdout' | 'stderr'",
    },
    over: {
      description: '是否运行完毕',
      type: 'boolean',
      required: true,
    },
  }}
/>

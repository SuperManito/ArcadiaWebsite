---
title: 新消息通知
---

系统产生新消息时推送，前端用于刷新未读消息数量与消息列表。

<Callout icon={false}>
接口路径：`/api/ws`  
事件名称：`message:new`  
方向：服务端 → 客户端
</Callout>

    type: {

    },
    title: {
      description: '消息标题',

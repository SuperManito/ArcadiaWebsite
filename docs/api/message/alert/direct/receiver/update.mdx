- ReceiverOverrideInput

键存在 = 覆盖规则主体对应项，键缺失或值为 `null` = 沿用规则主体，表以外的键直接报错。提供该字段即整体替换现有自定义：缺省的键清除对应自定义，不传该字段则清除全部自定义。详见[推送自定义](/docs/api/message/alert/direct/schema#推送自定义)。

import { GET } from '@/components/RequestTag';

<GET>/api/update/check</GET>

执行真实更新检测（git fetch + Releases API），返回检测状态、当前版本与可更新目标。并发请求复用同一次检测；更新任务执行中拒绝检测；主动检测不推送消息中心通知。

## 请求

无请求参数。

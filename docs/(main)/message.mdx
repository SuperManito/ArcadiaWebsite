平台消息中心提供了统一的消息推送与管理，具备通知聚合能力，您可以将业务消息集中推送至此。  
消息中心内置自动去重机制，消息本体支持最大字符数：`标题 200` `内容 20000`，超出部分将被截断。

## 监控告警

监控告警用于对 **消息中心** 的每条入库消息进行实时监测，命中告警规则后自动通过你配置的通知渠道推送告警，是替代旧版脚本推送的全新方案。

功能由 **通知渠道** 与 **告警规则** 两部分组成：

- **通知渠道**：对接外部推送服务（如 Bark、钉钉）的统一配置与管理，支持连接测试与通用消息模板，详见 [通知渠道](/docs/channel)。
- **告警规则**：定义**什么消息需要告警**以及**告警到哪里**，在”消息中心 - 监控告警“中管理。规则可按消息 **分类**（如定时任务、系统事件）与 **级别**（信息、警告、错误、成功）圈定监控范围，再对消息 **标题 / 内容** 设置匹配条件（支持文本包含、正则等多种运算符，可 and / or 组合），并关联一个或多个通知渠道。

消息入库后会非阻塞地触发规则求值，命中的规则会同时向其关联的全部通知渠道推送，单个渠道发送失败不影响其余渠道。

<Accordions type="multiple">
  <Accordion title="SDK" id="对接消息中心-sdk">
    SDK 位于项目 `utils/message-sdk` 目录下，零外部依赖，仅支持本地环境调用。

    ```javascript tab="Node.js (ESM)"
    async function sendArcadiaMessage(title, content, type = 'info') {
      try {
        const { push } = await import('/arcadia/utils/message-sdk')
        await push(title, content, type)
      } catch (error) {
        console.error('推送消息失败：', error)
      }
    }

    // 推送 info 类型消息（默认）
    await sendArcadiaMessage('备份完成', '数据库备份已成功完成')
    // 推送 success 类型消息
    await sendArcadiaMessage('版本更新', 'v2.1.0 已发布', 'success')
    ```

    ```javascript tab="Node.js (CommonJS)"
    async function sendArcadiaMessage(title, content, type = 'info') {
      try {
        const { push } = require('/arcadia/utils/message-sdk')
        await push(title, content, type)
      } catch (error) {
        console.error('推送消息失败：', error)
      }
    }

    !(async () => {
      // 推送 info 类型消息（默认）
      await sendArcadiaMessage('备份完成', '数据库备份已成功完成')
      // 推送 success 类型消息
      await sendArcadiaMessage('版本更新', 'v2.1.0 已发布', 'success')
    })()
    ```

    调用导出方法 `push(title, content, type)` 

    | 参数 | 必填 | 说明 |
    |------|------|------|
    | title | 是 | 消息标题 |
    | content | 是 | 消息内容 |
    | type | 否 | 消息类型，默认 `info`，可选值：`info`、`warn`、`error`、`success` |

    返回值：推送成功返回 true，推送失败抛出 Error

    其它语言建议使用下方的本地 HTTP 请求方式

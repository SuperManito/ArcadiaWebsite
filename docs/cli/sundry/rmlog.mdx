---
title: 清理日志
description: 删除代码文件的运行日志以及项目产生的各类日志文件
---

```bash
arcadia rmlog
```

无参数运行时，本地文件日志默认删除 `7` 天以上的记录；后端业务数据（系统日志、已读消息、定时任务历史）的保留天数由控制面板《个人设置 - 通用》中的“数据与日志清理”配置控制。

Arcadia 平台默认不设置自动定时清理日志，你可以在控制面板《定时任务》中创建个人定时任务来实现自动清理

```bash title="删除指定天数的日志"
arcadia rmlog <days>
```

指定天数后，本地文件日志和后端业务数据均按该天数执行清理，将临时覆盖通用设置中的保留天数配置。
